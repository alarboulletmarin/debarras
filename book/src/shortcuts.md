Every line of the help panel (`F1`), with the keys of Linux and Windows. On macOS, read `Cmd` for `Ctrl`.

## The plan

| Keys | Action |
|---|---|
| Click | Open a folder; tick or untick a plot that can be freed |
| `Esc` / `Backspace` | Back to the parent folder (also a right click, or the path above the plan) |
| `O` | Show the hovered item in the file manager |
| Hatching | Can go without loss: rebuilt or downloaded again when needed |
| Dots | Large, to review: you judge |

## Folders

| Keys | Action |
|---|---|
| `Ctrl+O` | Choose a folder to scan (a folder dropped on the window too) |
| `F5` / `Ctrl+R` | Scan the same folder again |

## The app

| Keys | Action |
|---|---|
| `T` | Next theme (kept for the next launch) |
| `F1` | This help |
| `Ctrl+Q` | Quit |
